# Guardian (Documentation)

This branch contains the documentation for the **Guardian** mod.

Guardian is a server-side Minecraft mod that protects the area around the
world spawn from PvP and explosions.

## What's in this branch

| File | Description |
|------|-------------|
| `UPDATES.md` | Release roadmap and changelog |
| `fabric-1.21.1.md` | Guardian for Fabric 1.21.1 |
| `neoforge-1.21.1.md` | Guardian for NeoForge 1.21.1 |

There is no code in this branch - it exists purely for documentation.
Source lives on the code branches (e.g. `main`).
